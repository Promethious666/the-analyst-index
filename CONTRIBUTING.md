# Contributing

Corrections and carefully evidenced additions are welcome. A proposal should identify the canonical upstream repository, explain the defensive use case, describe target interaction and data handling, state setup assumptions, name typical outputs and include a meaningful limitation.

Do not submit affiliate links, copied marketing text, unverified security claims, credentials, sensitive investigation data or tools whose primary value depends on unauthorised access. Automated discovery is candidate evidence only and does not guarantee acceptance.

All changes must pass the existing tests, linting and production build. Submissions may be rewritten for consistency or declined when evidence is insufficient.
