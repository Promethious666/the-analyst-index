The dashboard combines reviewed technical notes with automatically collected information from public sources.

New repository links and rules need checking. A link mentioning a CVE does not prove that an exploit works or that a rule will stop it.

If a source cannot be reached, its earlier information is kept. Data sources shows when each check last succeeded.
