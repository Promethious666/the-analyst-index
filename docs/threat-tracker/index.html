How this tracker works

Reviewed briefs describe public research. Scheduled collection checks CVE records, CISA's Known Exploited Vulnerabilities catalogue, EPSS and public repository references.

Automatic findings enter an unreviewed evidence section. They cannot rewrite a reviewed technical assessment or become a validated detection rule.

Repository mentions are leads, not proof that an exploit works. Absence from a catalogue does not establish that exploitation has not occurred.

Report exports preserve the evidence status, source dates and collection failures visible here. Organisational exposure remains not assessed.

Scheduled refreshes are best effort. Check source health and the last successful collection before relying on freshness.
